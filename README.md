# Lab 2 — Vector laboratory

Based on the course TE_Group_EN examples. Includes editable vectors, origin arrows, sum, dot product, cross product, cross length and angle. Starts with a=(3,4,0), b=(1,0,0): angle 53.13°. Zero vectors hide their arrows and report an undefined angle.

Run `npm ci` and `npm run dev`. Select Lab 2 for vectors, or the ray–plane challenge for the formula intersection and THREE.Raycaster comparison shown on screen. The challenge intersects the plane at (-3,0,4). `npm run build` builds all pages. Run `node --test tests/lab2.test.js` for numerical checks.
