# Lab 1 — Hello, three.js

Based on the course TE_Group_EN examples. Implements the October 8, 2026 lab: perspective camera (75°, 0.1–1000) at (0, 1, 5), full-window renderer, orange 1.5-unit cube, ambient and directional lights, continuous rotation, and optional OrbitControls. The canvas follows window resizing.

Run `npm ci`, then `npm run dev` and open the displayed local URL. Select Lab 1. Drag to orbit and scroll to zoom. `npm run build` builds all example pages.

The commit author date matches the Classroom material date by request; it does not indicate the original completion or submission time. The committer date records actual commit creation.
